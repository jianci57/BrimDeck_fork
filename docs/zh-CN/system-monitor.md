# 系统监控的读数

系统监控页显示 CPU、GPU、内存、网络、硬盘、温度、功耗、电池和帧率。本文说明各项读数的来源与限制。相关设置在“设置 › 显示与读数”中。

所有读数只在本机读取和显示，不保存、不上传。除特别说明外，读取不需要管理员权限，也不安装驱动。

## 读数一览

| 读数 | 默认 | 开关位置 | 说明 |
| --- | --- | --- | --- |
| CPU、内存、下载、上传 | 显示 | 展开时 › 显示的内容 | CPU 另有每个核心的使用率 |
| GPU | 显示 | 展开时 › 显示的内容 | 有多块显卡时可选择显示哪一块 |
| 占用最高的应用 | 显示 | 展开时 › 显示的内容 › 进程列表 | 按 CPU 或内存排序，点击应用查看详情 |
| 硬盘 | 显示 | 展开时 › 显示的内容 › 硬盘 | 只列内置硬盘 |
| 整机功耗与本机电池 | 显示 | 展开时 › 显示的内容 › 功耗与电池 | 没有电池的电脑不显示电池 |
| 温度 | 不显示 | 展开时 › 显示的内容 › 温度 | CPU、GPU 和固态硬盘 |
| 帧率 | 不显示 | 展开时 › 显示的内容 › 帧率 | 首次开启需要授权 |

刘海与胶囊中显示哪些读数，在“收起时”一节中选择。

## 选择展开页显示什么

“展开时”一节的“显示的内容”中，每个读数有一个选择块，点按切换显示：CPU、GPU、内存、下载、上传、帧率、硬盘、功耗与电池、进程列表、温度。温度显示在 CPU、GPU 和硬盘旁边。

下方的“页面顺序”是展开页的示意图，每一块对应页面上的一个区域：CPU 与 GPU 是一块，内存、下载与上传是一块，帧率、硬盘、功耗与电池各是一块。拖动一块，或选中后按 Alt+↑/↓，可以调整它在页面上的上下顺序。内存与网速在同一块中，内存一行、网速一行；面板很矮时两者并到同一行，顺序不变。下载与上传在网速那一行左右并排，左右拖动可以交换；上下拖动下载或上传，内存、下载与上传整块一起移动。在块内上下拖动内存，可以交换内存与网速的位置，拖出这一块时整块一起移动。进程列表以虚线框表示，它的位置随面板大小变化，在右侧或下方，不能拖动。“恢复默认顺序”只恢复顺序，不改变哪些项目显示；已经是默认顺序时显示为灰色。

- 这里的勾选只管展开页，“收起时”的勾选只管刘海和胶囊，两处互不影响。
- 页面会按选中的项目自动排版：只选一项时它占满页面；空间不够时先去掉帧率、硬盘等较次要的行，再压缩网速和内存，不会重叠或超出页面；下载与上传共用一行，可只显示其中一个。
- 全部不选时，展开页显示提示和“打开设置”按钮，并且展开页不请求任何数据。没有选中的读数不会被展开页请求；收起的行和延迟保留窗口仍会读取它们需要的数据。
- 没有改过这些开关和顺序时，展开页与升级前完全一样；旧的显示进程列表、硬盘、功耗与电池、帧率开关已并入“显示的内容”。
- CPU 与 GPU 都显示时，点击展开页上较小的那一个，可以切换哪一个显示为大图。

## CPU 与 GPU

- CPU 占用率按处理器忙碌时间计算，与 Windows 11 24H2 起的任务管理器一致。
- 有多块显卡时默认显示独立显卡。点击页面上的大号 GPU 读数可以切换到下一块，也可以在“通用 › 显卡”中指定。
- GPU 占用率默认使用显卡驱动的读数（NVIDIA、AMD、Intel），与 nvidia-smi、HWiNFO 一致；驱动没有读数时按任务管理器的方式计算。驱动读数不正确时，可以在“来源 › 显卡占用率”中改为 Windows。

## 核心显示：柱状与点阵

CPU 的每个逻辑处理器默认画成一根细柱。线程很多的电脑（例如 192 线程）放不下这么多柱子，所以可以改用点阵：每个逻辑处理器一个小方块，从上到下、再向右排列，最快的一类核心排在最前；方块越亮表示占用越高，占用达到警告或严重级别时换成对应的状态颜色。点阵在展开页、刘海、胶囊和侧边栏里都能用；在展开页指向方块会显示该核心的名称、占用和频率，收起的读数本来就不响应鼠标，所以没有提示。

在“通用 › 核心显示”中选择：

- 自动（默认）：核心不多时与以前一样画柱；柱子会窄到不足 2 个物理像素（展开页），或在收起时的读数里放不下（约 37 个核心以上）时，改用点阵。普通的 8 到 32 核电脑不受影响。
- 柱状：始终画柱。
- 点阵：始终画点阵。

点阵的方块尽量大，按显示缩放取整到物理像素；放得下时留出一像素的间隙，再小则方块相接。柱状图里表示频率的横线，点阵里没有，需要时指向方块查看。

## 流量统计

展开页的网速一行在下载、上传速率后面显示一段时间内的流量，例如“当天 2.31 GB”；空间不够时只显示数字，再窄时只在悬停提示中显示。收起行的读数表中有“累计下载”“累计上传”两行，以双箭头图标显示，可以分别打开，与速率互不影响。

统计时长在“通用”一节的“流量统计时长”中选择：

- 当天：从本地时间 0 点算起，每天 0 点重新开始。
- 1 天、7 天、30 天：从现在往前推相应的时长。

流量取自 Windows 自己的记录，与 Windows 设置中的“数据使用量”相同，因此包括 BrimDeck 没有运行时的流量，重启后也不清零。统计 Wi-Fi、有线网络和移动网络，VPN 等虚拟网络的流量已计入它所经过的网络，不重复计算。Windows 的记录会稍晚更新，刚刚产生的流量可能过一段时间才计入。

## 硬盘

- 按盘符显示已用空间；页面放不下时，其余盘符合并为一行。
- 只列内置硬盘，不含 U 盘、SD 卡、移动硬盘、网络盘和光驱。

## 温度

“显示温度”默认关闭。读不到的温度不显示。

| 项目 | 来源 |
| --- | --- |
| CPU | 默认来自主板固件提供的 ACPI 热区。许多电脑没有这项数据，有的电脑读到的是主板而不是 CPU 本身的温度 |
| GPU | 显卡驱动报告给 Windows 的温度，与任务管理器相同；没有时改用 NVIDIA、AMD、Intel 驱动自带的接口 |
| 硬盘 | 固态硬盘自己报告的温度。使用 RAID 模式（例如 Intel 快速存储技术）的硬盘不读取温度 |

读不到 CPU 温度时，有两种办法：

- 启用[增强传感器](enhanced-sensors.md)，由 BrimDeck 的传感器服务直接从处理器读取。
- 同时运行 HWiNFO（开启共享内存）或 LibreHardwareMonitor（开启远程网页服务器），BrimDeck 会从中读取。

温度的悬停提示会标明读数来源。

如果读取某一项温度或功率时电脑卡住，BrimDeck 下次启动时会停止读取这一项。已停止的项目列在“展开时”一节中，可以逐项重新开启。

## 整机功耗

页面显示整机功耗（单位 W）及其最近一分钟的曲线，悬停提示列出读数的组成与来源。读数按以下顺序选取：

1. **电脑自带的功率计**：直接测得的整机功耗。只有少数平板和服务器提供。
2. **电池放电功率**：笔记本用电池供电时，电池的放电功率就是整机功耗。
3. **各部件之和**：CPU 功率加上独立显卡的板卡功率（NVIDIA、AMD、Intel）。这是估算值，不含显示器、硬盘、风扇和电源损耗，悬停提示中会注明。

功耗只在系统监控页打开、或刘海与胶囊显示功耗时读取。NVIDIA 显卡的功率通过显卡驱动自带的 nvidia-smi 读取，且只在显卡有负载时读取，不会唤醒休眠的独立显卡。

读不到 CPU 功耗的电脑（例如部分 AMD 电脑）同样可以启用[增强传感器](enhanced-sensors.md)。

## 本机电池

笔记本和平板在功耗一行的右端显示本机电池：

- 电量，以及系统给出时的剩余时间或充满所需时间。接通电源时，电池图标中显示插头。
- 悬停提示中有充放电功率、Windows 电源模式、节电模式和电池健康度（满充容量与设计容量之比）。
- 用电池供电时，电量降到 25% 及以下用预警色，15% 及以下用告警色；接通电源时不变色。

这里显示的是电脑自身的电池。无线鼠标、键盘、耳机等设备的电量见[设备电量支持](devices.md)。

## 帧率

开启“显示帧率”后，页面在网速下方显示前台程序的帧率、程序名称和所在显示器的刷新率；前台程序没有在绘制时，显示最近一个在绘制的程序。

读取帧率需要把当前用户加入 Windows 的“Performance Log Users”组。首次开启时，Windows 会请求一次管理员确认，重新登录 Windows 后生效。帧率只在系统监控页打开、或刘海与胶囊显示帧率时读取。

## 配色

各项读数的颜色默认跟随面板主题，也可以在“通用”一节选择预设配色或自定义。
