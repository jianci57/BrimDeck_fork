New
- New "Displays and profiles" page in Settings: several profiles can be saved, each display can use its own profile or hide the panel, and the profile switches automatically while a given app is running or in the foreground.
- New "Page layout" page for the shelf (Settings > Shelf > Page layout): the clipboard can be shown as one line, three lines or blocks, and the file transfer as one line, two lines, a grid, a row or a column, in any combination.
- New stacked layout for the clipboard and file transfer.
- The shelf can show only the clipboard or only the file transfer (Settings > Shelf > Page layout > Show).
- Several items can be selected in the clipboard and file transfer: click with Ctrl or Shift held, or drag a box from an empty area. The right-click menu applies to all selected items.
- Pointing at a file shows Open, Show in folder, Remove and Details buttons; pointing at a clipboard entry shows Add to favorites, Paste as plain text and Details buttons.
- New traffic statistics in the system monitor. VRAM usage can be shown in the collapsed row and on the expanded page.
- New CodeAgent quota and usage source.
- New Command Code quota and usage source, and a Command Code API source with a key entered by hand.
- New WorkBuddy (China) and WorkBuddy AI (international) quota and usage sources. Credits are read after you sign in through the browser in Settings.
- New Xiaomi MiMo quota and usage sources: the desktop subscription, automatic reading, and Xiaomi MiMo API and Xiaomi MiMo Token Plan with keys entered by hand.
- New "Kimi Open Platform" source with a key entered by hand. It shows the account balance billed by usage on the open platform.
- Antigravity's weekly Argon quota is supported.
- New "Core display" setting (Settings > Display and readings): choose Auto, Columns or Dot matrix. With many cores, Auto switches to the dot matrix, so the columns no longer go past their space.
- A panel opened with a shortcut can be used with the keyboard.
- Battery levels are supported for many more brands of mice, keyboards, headsets and controllers, such as MCHOSE, Glorious, Keychron, HyperX, Finalmouse, Lofree, MonsGeek, Alienware, RK, Sony INZONE, Jabra, SteelSeries, Logitech G headsets, Corsair, ASTRO, Audeze, BETOP, Flydigi, GameSir, 8BitDo and the Xbox 360 wireless controller. See the device support document for the full list.
- New "Read" switch in the device list in Settings. When it is off, BrimDeck sends nothing to that device. It turns off by itself if the device misbehaves while being read.
- New "Lyric area follows the line length" and "Title area follows the title length" switches (Settings > Style > When collapsed), off by default.
- New "Apply font to settings window" switch (Settings > General > Appearance and language), off by default. When it is on, the settings window also uses the chosen interface font.
- New "Keep history after exit" switch for the clipboard (Settings > Clipboard). When it is on, the history is no longer cleared when BrimDeck exits, and entries older than "Keep for" are deleted.
- QueMusic is supported.
- New "Community" item on the About page, which shows the community groups and other ways to get in touch.

Improvements
- The system readings on the expanded page can be chosen and rearranged.
- AI usage shows up faster at startup: whatever is read first is shown first.
- "Keep on top" works in a new way and works better alongside apps such as MyDockFinder.
- Any number of AI quota apps can be added, and up to 7 are shown at once.
- Newly added apps use Codex as their quota source and usage app by default.
- Claude's Max 20x plan is shown as Ultra, and Max 5x as Max.
- Antigravity quotas can be read when Antigravity runs as administrator or is installed in a custom folder.
- Antigravity token usage works with the new version of Antigravity.
- Reading the token details of a merged Cursor plan takes fewer requests. If reading is interrupted, what has been read is kept.
- Battery levels of peripherals are read in a better way.
- When the notch is docked vertically to the left or right edge of the screen, device battery levels are shown one device per line.
- "♪" is no longer shown when the gap between two lyric lines is shorter than 5 seconds; the previous line stays until the next one starts. This applies to all lyric sources.
- With "Lyric area follows the line length" on, the area changes width more smoothly and the text moves with its edges.
- When updating, the installer backs up the old version first and restores it if installing the new version fails or is canceled. When an in-app update fails, BrimDeck asks whether to try again.
- The clipboard history and the file transfer list are saved without encryption, so saving is faster when there are many entries. Formatting copied from web pages, Word and other apps is stored separately on disk, which uses less memory.
- Some background checks stop while the display is off, so fewer resources are used.
- Some displayed content and animations are improved.
- Some content in Settings is improved.

Fixes
- Fixed Claude quotas read last time not being shown after upgrading from an older version while the quota service could not be reached (for example when rate limited or offline).
- Fixed lyrics briefly jumping back to the previous line when the player reports a slightly earlier position.
- Fixed the part of the capsule above the taskbar being covered by the taskbar while the Start menu or search is open.
- Fixed GPU readings briefly being too high when the panel expands.
- Fixed the right-click menu in the clipboard and file transfer not closing, and the panel not collapsing, when you click outside BrimDeck while the menu is open.
- Fixed the file transfer list flickering while scrolling.
- Fixed the text and icon of the "Kept" and "Cleared on exit" tags in clipboard categories sitting too high or too low.
- Fixed closing the quota source drop-down also expanding or collapsing that app's row.
- Fixed readings that are turned off leaving empty lines in the column when the capsule is docked to the left or right edge of the screen.
- Fixed the fitted length being shorter than the content when the capsule is docked to the left or right edge of the screen and BrimDeck's scale is 150%.

新功能
- 新增“显示器与配置”设置页：可以保存多套配置，为每台显示器指定配置或不显示面板，并在指定的应用运行或位于前台时自动切换配置。
- 中转站新增“页面布局”设置页（设置 > 中转站 > 页面布局）：剪贴板可选单行、三行、方块，文件中转可选单行、双行、网格、横排、竖排，可以任意组合。
- 剪贴板与文件中转增加叠放布局。
- 中转站可以只显示剪贴板或只显示文件中转（设置 > 中转站 > 页面布局 > 显示内容）。
- 剪贴板与文件中转支持多选：按住 Ctrl 或 Shift 点选，或从空白处框选，右键菜单对所有选中的条目生效。
- 指针移到文件上时显示打开、在文件夹中显示、移除、查看详情按钮；移到剪贴板条目上时显示加入常用、粘贴为纯文本、查看详情按钮。
- 系统监控新增流量统计；显存占用可以在收起行和展开页面直接显示。
- 新增 CodeAgent 额度与统计来源。
- 新增 Command Code 额度与统计来源，以及手动填写密钥的 Command Code API 来源。
- 新增 WorkBuddy（国内版）和 WorkBuddy AI（国际版）额度与统计来源。在设置中通过浏览器登录后读取积分。
- 新增 Xiaomi MiMo 额度与统计来源，包括桌面订阅、自动读取，以及手动填写密钥的 Xiaomi MiMo API 和 Xiaomi MiMo Token Plan。
- 新增手动填写密钥的“Kimi 开放平台”来源，显示开放平台按量计费的账户余额。
- Antigravity 支持 Argon 周配额。
- 新增“核心显示”设置（设置 > 显示与读数），可选择自动、柱状或点阵。核心数很多时自动改用点阵，不再超出宽度。
- 用快捷键打开的面板可以用键盘操作。
- 外设电量支持大幅扩展，新增大量鼠标、键盘、耳机和手柄品牌，例如迈从、Glorious、Keychron、HyperX、Finalmouse、Lofree、MonsGeek、Alienware、RK、索尼 INZONE、Jabra、赛睿、罗技 G 系列耳机、海盗船、ASTRO、Audeze、北通、飞智、盖世小鸡、8BitDo 和 Xbox 360 无线手柄。完整列表见设备支持文档。
- 设置的设备列表新增“读取”开关。关闭后，BrimDeck 不再向该设备发送任何请求；读取时设备出现异常，开关会自动关闭。
- 新增“歌词区域随歌词长度变化”和“歌名区域随歌名长度变化”开关（设置 > 样式 > 收起时），默认关闭。
- 新增“字体应用到设置窗口”开关（设置 > 常规 > 外观与语言），默认关闭。开启后，设置窗口也使用所选的界面字体。
- 剪贴板新增“退出后保留历史”开关（设置 > 剪贴板）。开启后，退出 BrimDeck 时不再清除记录，超过“保存时长”的记录会自动删除。
- 新增适配 QueMusic。
- 关于页新增“交流”，可以查看交流群等交流方式。

改进
- 展开页的系统监控项显示内容可以自选并调整位置。
- AI 用量启动更快，先读取到的内容先显示。
- “持续置顶”改用新的方式，与 MyDockFinder 等软件的兼容性更好。
- AI 配额应用的数量不再受限，最多同时显示 7 个。
- 新添加的应用默认使用 Codex 作为配额来源和统计应用。
- Claude 的套餐 Max 20x 显示为 Ultra，Max 5x 显示为 Max。
- Antigravity 以管理员身份运行或安装在自定义目录时，也能读取额度。
- Antigravity 的 Token 用量统计适配新的版本。
- 读取 Cursor 合并套餐的 Token 明细时请求次数更少；读取中断时，已读取的部分会保留。
- 外设电量读取方式改进。
- 刘海竖向贴靠在屏幕左侧或右侧时，设备电量改为每个设备占一行。
- 歌词中两句之间的空档不足 5 秒时不再显示“♪”，上一句一直显示到下一句开始。适用于所有歌词来源。
- “歌词区域随歌词长度变化”开启时，区域宽度变化更平缓，文字随边缘一起移动。
- 安装更新时会先备份旧版本，新版本安装失败或被取消时恢复旧版本。应用内更新出错时，会询问是否重试。
- 剪贴板记录与文件中转列表改为不加密保存，记录很多时保存更快。网页、Word 等复制时附带的格式单独保存在磁盘上，内存占用更少。
- 显示器熄灭时停止部分后台检查，资源占用更低。
- 部分显示内容与动画效果优化。
- 部分设置显示内容优化。

- 修复播放器报告的进度略有回退时，歌词短暂跳回上一行的问题。

- 修复剪贴板与文件中转的右键菜单打开时，点击 BrimDeck 以外的地方菜单不关闭、面板也不收起的问题。
- 修复文件中转列表滚动时闪烁的问题。
- 修复剪贴板分类中“一直保留”“退出时清除”标签的文字和图标偏上或偏下的问题。
- 修复配额来源下拉框收起时，同时展开或收起该应用行的问题。
- 修复胶囊贴靠在屏幕左侧或右侧时，已关闭显示的系统读数在竖列中留下空行的问题。
- 修复胶囊贴靠在屏幕左侧或右侧、BrimDeck 缩放为 150% 时，自适应长度比内容短的问题。
